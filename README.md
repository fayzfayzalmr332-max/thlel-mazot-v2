# 🛢️ ثُلَّ المازوت — THLEL MAZOT

لوحة تحليل تفاعلية **متقدمة** لأسواق الطاقة العالمية (الغازويل/المازوت وزيت التدفئة) وقرينة المحفزات
الاقتصادية والجيوسياسية المحلية في سوريا — مبنية بـ **Python + Streamlit + Plotly**.

> الاسم مستلهم من مصطلح «ثُلَّ المازوت» — إشعار توافر مادة التدفئة في سوريا. اللوحة تهدف أن تكون
> «الإشعار» الرقمي: هل هناك ضغط إمداد عالمي قادم سيرتد على السوق المحلي أم انفراج؟

---

## ✦ المزايا

| الميزة | الوصف |
|---|---|
| 📈 **بيانات أسواق حية** | عقود الغازويل الآجلة (GCL=F / بديل HO=F مبني على زيت التدفئة الأمريكي ومحوّل إلى USD/طن)، خام برنت، مؤشر الشحن (BDI أو بدائله المتاحة كـ BDRY/SEA)، وسعر صرف USD/SYP (رسمي + موازٍ). |
| 🧮 **نموذج تسعير نظري شفاف** | رحلة السعر من FOB لندن → CIF (شحن + تأمين + علاوة عقوبات) → سعر المستهلك (ل.س/لتر) ومقارنتها بالتسعيرة الرسمية المرجعية (أيلول 2026 — قابلة للتحرير). |
| 🚀 **محرك «الصاروخ والريشة»** | كشف الارتفاع الحاد السريع (ROCKET) مقابل الانحدار البطيء الحثيث (FEATHER) عبر سرعات العوائد ومؤشر عدم التماثل. |
| 🛰️ **رادار جيوسياسي مفتوح النطاق** | مسح Google News (إنجليزي/عربي) لملفات: مصفاة بانياس، مصفاة حمص، مضيق هرمز، قرارات التسعير، العقوبات، سعر الصرف + اكتشاف «مواضيع ناشئة» غير مصنّفة مسبقًا. |
| 🎯 **لوحة الإشارة** | مؤشر توتر وزني (0-100) → 🟢 ارتياح / 🟡 متابعة / 🔴 أزمة إمداد، مع قواعد ترجمة إلى إجراءات. |
| 🔔 **تنبيهات Telegram** | إشعارات فورية عند: حركة غازويل ≥ 30 USD/طن، تغيّر إشارة الهيرو، أو كلمة محلية حرجة من الرادار — مع منع التكرار عبر كاش الحالة. |
| 📄 **تقرير PDF يومي (RTL)** | زر تنزيل مباشر من اللوحة: شلال التسعير + مصفوفة الإشارة + المحفزات الجيوسياسية، بتشكيل عربي حقيقي. |
| 🛡️ **صمود كامل** | تسلسل مصادر: حي → ذاكرة TTL → كاش قرص → **محاكاة اصطناعية** (اللوحة لا تنطفئ دون إنترنت). |
| 🏷️ **شفافية المصدر** | كل بطاقة تعرض شارة مصدرها (مباشر/ذاكرة/محاكاة). |

```
 ├── src/ui/theme.py           سمة داكنة مخصصة + RTL
 ├── src/ui/charts.py          رسوم Plotly + SVG sparklines بلا اعتماديات

config/settings.yaml           كل المتغيرات والمعايير والافتراضيات
scripts/run_news_scan.py       مسح دوري CLI للجدولة (cron)
tests/                         pytest — 100% دون شبكة
```

## ✦ الإعدادات — `config/settings.yaml`

كل شيء قابل للتعديل دون لمس الكود:

| القسم | ماذا يضبط |
|---|---|
| `app` | العنوان، دورية التحديث، دليل الكاش |
| `market.tickers` | مرشحو الرموز لكل مقياس، الوحدات، عوامل تحويل الوحدات، قيم المحاكاة |
| `fx` | الأسعار الافتراضية للنظام (رسمي/موازٍ) وهامش الانحراف |
| `pricing` | لتر/طن، التأمين، أساس الشحن وحساسيته، هامش التكرير، التوزيع، الضريبة، علاوة العقوبات، وخطا التسعيرة الرسمية |
| `momentum` | نوافذ الزخم وعتبات الانطلاق/الانحدار |
| `sentiment` | الأوزان ونطاقات الدرجات (GREEN/YELLOW/RED) |
| `news` | استعلامات Google News (ع/إ)، عدد البنود، عمر الذاكرة، نصف العمر لتلاشي الضغط |

> **تسعيرة أيلول 2026:** القيم المبدئية في `pricing.official_baseline` تمثيلية قابلة للتحرير —
> حدّثها من الشريط الجانبي أو من الملف فور صدور المرسوم الفعلي.

## ✦ تنبيهات Telegram (تفعيل آمن)

**🔒 التخزين الآمن للاعتماديات (لا تُودَع في settings.yaml المُصدَّر):**

| القناة | أين | متى |
|---|---|---|
| `.streamlit/secrets.toml` (مهمَّش من Git) | `TM_TELEGRAM_BOT_TOKEN` / `TM_TELEGRAM_CHAT_ID` | محليًا وStreamlit Cloud |
| متغيرات بيئة | `TM_TELEGRAM_BOT_TOKEN` / `TM_TELEGRAM_CHAT_ID` | خوادم/cron (Linux) |

```bash
# Windows (محادثة دائمة لكل الجلسات):
setx TM_TELEGRAM_BOT_TOKEN "…"
setx TM_TELEGRAM_CHAT_ID "…"
# Linux:
export TM_TELEGRAM_BOT_TOKEN="…"
```

`config/settings.yaml` يحوي `bot_token`/`chat_id` بصيغة `PLACEHOLDER_*` فقط — تُعامل دائمًا كقيم فارغة،
ومفتاح `enabled: true` **لا يُفعّل البوت إلا عند وجود اعتماديات حقيقية** (placeholders لا تُفعّله أبدًا).

**خطوات الإعداد:**
1. انشئ البوت في **@BotFather** → ` /newbot` → انسخ التوكن إلى `secrets.toml` أو متغيّر البيئة.
2. أرسل `chat_id`: عبر **@userinfobot** ثم ضعه في `secrets.toml`.
3. **افتح `t.me/<bot_username>` واضغط /start مرة واحدة** — شرط أساسي في Telegram حتى يقدر البوت إرسال رسائلك.
4. شغّل الفاحص: `python scripts/verify_telegram.py` — سيؤكد `getMe` ويُرسل رسالة تجريبية.
5. المحفزات: حركة الغازويل ≥ `price_move_threshold_usd_t` (±)، تغيّر درجات الهيرو، وورود الكلمات
   الحرجة في أخبار الرادار بشدة ≥ `min_news_severity` (منع تكرار عبر `alerts_state`).

**🚨 تنبيه أمني مهم:** إن سبق أن ظهر التوكن في رسالة/مستند/محادثة مكشوفة، **ألغِه فورًا** في BotFather:
`/mybots ← البوت ← API Token ← Revoke current token`، ثم انسخ الجديد إلى `secrets.toml` —
هذا يُبطل أي استخدام غير مصرح للتوكن القديم ويُبقي الكود بلا أي تعديل (سطر واحد فقط).

## ✦ تقرير PDF اليومي

- في تبويب **«🎯 الإشارة والقرار»** زر **«📄 تحميل تقرير الوضع اليومي (PDF)»**.
- المحتوى: شريط الحالة الملوّن، جدول الأسعار، مصفوفة الإشارة (أشرطة فرعية)، تفكيك السعر النظري
  (شلال)، والمحفزات الجيوسياسية النشطة — بنص عربي مشكّل (Tahoma/Segoe) مع تخفيض آلي لإنجليزية
  في بيئات بلا خط عربي.
- يعتمد على `fpdf2` + `arabic-reshaper` + `python-bidi` (مضافون في `requirements.txt`).

## ✦ الخوارزميات بعجالة

**النموذج النظري** (ل.س/لتر):
```
السعر النظري = [(الغازويل العالمي + الشحن + التأمين + علاوة العقوبات)
                × سعر الصرف الموازي ÷ ~1190 لتر/طن
                + هامش التكرير + هامش التوزيع] × (1 + VAT)
```

**الصاروخ والريشة**:
```
ROCKET  ⟸ R(5d) ≥ +6%  ∨  (R5d>0 ∧ سرعة الصعود > 2×سرعة الهبوط)
FEATHER ⟸ R(30d) ≤ −4% ∧ أيام هابطة ≥ 12 ∧ متوسط الزحف ≤ 0.35%/يوم
عدم التماثل = سرعة الصعود المعاصرة ÷ سرعة الهبوط المعاصرة
```

**مؤشر الضغط الجيوسياسي** = مجموع متلاشٍ أُسيًّا (نصف عمر 36 ساعة) لدرجات الشدة المصنّفة
مع تشبع صاعد `100·(1−e^(−0.22·Σ))`.

**الإشارة** = Ω·[جيوسياسة 35%، زخم 30%، فجوة تسعير محلي 20%، شحن 15%].

## ✦ الانتشار (Production)

**Docker:**
```bash
docker build -t thlel-mazot .
docker run -d -p 8501:8501 thlel-mazot
```

**Streamlit Community Cloud:** ادفع المستودع إلى GitHub → New App → ملف `app.py` — يعمل مباشرة.

**مسح الأخبار الدوري (cron):**
```bash
# كل 30 دقيقة
*/30 * * * *  cd /path/to/thlel-mazot && python scripts/run_news_scan.py --force >> data/reports/news_scan.log 2>&1
```
النواتج: `data/reports/news_snapshot_*.csv` و `news_metrics.json` (قابلة للاستهلاك من أنظمة الإنذار).

**تلميحات:**
- قلّل تواتر Yahoo بـ `app.mem_cache_seconds` (الافتراضي 300ث) — Yahoo يقيد المعدل.
- أضف خلاصات/استعلامات جديدة في `news.google_queries` دون كود.
- غيّر عتبات التصنيف في `news/half_life_hours` حسب متطلباتك الزمنية.

## ⚠️ تنبيهات منهجية

- **أداة استرشاد وتحليل، وليست سعرًا رسميًا ولا نصيحة استثمارية.**
- أسعار التسعيرة المرجعية قيم مبدئية تُحدَّث يدويًا من المراسيم الرسمية.
- بيانات الأسعار من مصادر عامة وقد تتأخر عن الشاشات المؤسسية؛ الوضع التجريبي (المحاكاة) معلَّم بوضوح.
- نموذج التسعير تقديري (هامش تكرير/توزيع/عقوبات) ويجب معايرته على معاملات فعلية PRIVATE.
